1. CRM

Como manejar una consulta hasta que se confirme

Cargar la consulta

Usar Nueva consulta. Completar clienta, telefono, fecha de consulta, fecha tentativa del evento, homenajeado/a, edad, tipo, canal, tematica, propuesta, responsable y observaciones.

Mirar la accion sugerida

Cada tarjeta indica que sigue: Completar datos, Enviar presupuesto, Hacer seguimiento, Marcar como senado, Pasar al Dashboard o Actualizar Dashboard.

Revisar datos faltantes

Si faltan datos minimos, el CRM los muestra para evitar pasar registros incompletos a operacion.

Usar la ficha lateral

Al abrir un registro se ven datos principales, historial breve, proxima accion y estado de sincronizacion con CRM, Dashboard y Proceso.

Pasar al Dashboard

Solo cuando el estado sea Senado o Pagado completo. El sistema valida datos, pide confirmacion y crea o actualiza el mismo evento sin duplicarlo.

Estados comerciales, en orden de uso

Consulta nueva Datos incompletos Seguimiento Presupuesto enviado Senado Pagado completo Realizado Cancelado
Enviar presupuesto no envia mensajes automaticos. Por ahora guia la accion o cambia el estado. El contacto real con la clienta lo hace el equipo.
Si aparece error al pasar al Dashboard: tocar Actualizar, volver a intentar y mandar captura si se repite. El sistema ahora muestra detalle tecnico para detectar si fue conexion, Supabase o navegador.
2. Dashboard

Donde se opera el evento confirmado

Para que sirve

  • Cargar o corregir datos de eventos operativos.
  • Cambiar etapa comercial y estado operativo.
  • Editar responsable desde desplegable.
  • Editar fecha del evento.
  • Controlar facturacion, sena y saldo.
  • Agendar el evento en Google Calendar.
  • Exportar o importar datos cuando haga falta.

Que no deberia vivir aca

  • Consultas iniciales sin confirmar.
  • Seguimientos comerciales que todavia no son evento.
  • Reuniones con clientas: eso va en CRM.
  • Analisis general: eso va en Panel de control.
Agendado: el estado cambia a verde solo cuando Google Calendar confirma que el evento fue creado. Si no confirma, debe quedar como Sin agendar.
3. Proceso

Como preparar boceto, checks y materiales

Elegir el evento

Debe aparecer si ya fue pasado al Dashboard o creado como evento operativo.

Marcar avances

Consulta, diseno y venta, traspaso a produccion, produccion, montaje y cierre.

Subir boceto

Permite JPG, PNG, PDF, DOC y DOCX. Esperar la barra/mensaje de guardado antes de salir.

Cargar materiales

Agregar un material por casilla. Tocar Agregar item para sumar otra casilla y Guardar materiales para sincronizar.

Cuidados importantes

  • No pegar toda la lista en una sola casilla si Juli debe marcar item por item.
  • No cerrar la pantalla mientras indica que esta guardando.
  • Si algo no se refleja, tocar Actualizar datos antes de volver a cargarlo.
  • Si hay observaciones largas, usarlas para detalle operativo, no para montos sensibles.
Cuando aparece en Proceso: normalmente despues de tocar Pasar al Dashboard desde CRM en una consulta Senada o Pagada completa.
4. Produccion

Ficha para preparar el evento

Que muestra

  • Boceto del evento.
  • Fecha, horario y direccion.
  • Clienta, homenajeado/a, edad y tematica.
  • Propuesta correspondiente.
  • Checklist de materiales.
  • Observaciones operativas debajo del boceto.

Estados de produccion

Listo para producir En preparacion Materiales listos Decorado Finalizado
Finalizado oculta el evento de Produccion. El sistema debe pedir confirmacion porque desaparece de esa vista. Si todavia quieren verlo, usar Decorado.
Para imprimir o guardar PDF: elegir el evento que se quiere imprimir. El archivo debe nombrarse con clienta, tematica y fecha del evento.

7. Agenda

Eventos y reuniones en Google Calendar

Eventos

  • Se agendan desde Dashboard.
  • Se comparten con el calendario de Happy Deco.
  • El sistema debe avisar 15 dias antes, 7 dias antes, 3 dias antes y el mismo dia cuando esas fechas tengan sentido.
  • Si el evento esta muy cerca, se usan recordatorios posibles y utiles.

Reuniones

  • Se agendan desde CRM.
  • Incluyen tema, fecha, horario, clienta, modalidad, presupuesto, tematica y detalles.
  • No deben compartir detalle sensible con Juli.
  • Se pueden elegir recordatorios manuales cuando haga falta.
Si alguien no ve el calendario, revisar que haya aceptado el calendario compartido y que este usando la cuenta correcta en su telefono.
8. Si algo falla

Soluciones rapidas antes de cargar de nuevo

No aparece en Dashboard

En CRM debe decir En Dashboard. Si dice Solo CRM o Faltan datos, todavia no fue enviado.

No aparece en Proceso

Actualizar datos. Si viene de CRM, confirmar que el pase al Dashboard fue exitoso.

No aparece en Produccion

Debe estar Listo para producir o tener boceto/materiales. Si esta Finalizado, se oculta.

No se ve en otro dispositivo

Entrar al link oficial, tocar Actualizar datos y evitar usar pestañas viejas abiertas.

No carga boceto

Probar archivo mas liviano y esperar la barra/mensaje de guardado.

Error de Supabase

Reintentar con Actualizar. Si vuelve a pasar, mandar captura con el detalle tecnico.
